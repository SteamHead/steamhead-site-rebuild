theMake.club organised its classes around three tables: the maker skills every member practised, an engineering-skills ladder from planning to online networking, and a grid of projects matched to each age.

## Maker skills

| Skill | Key topics |
|---|---|
| **Collaboration** | |
| Sharing | Tools, workload, ideas, spotlight |
| Group speaking | Timing, relevancy, sway, listening |
| Helping peers | Listening, helping, teaching |
| Project Management | Planning, role performance, documentation |
| **Technology** | |
| Engineering Design | Schematics, 3D modeling, electronics, programming, prototyping |
| Craft skills | Beauty, stability, effectiveness, efficiency |
| Collaborative assembly | Micro actions, project roles, effective use of assistance and vice versa |
| Research & Learning | Online skills acquisition, market research, social networking |
| **Communication** | |
| Verbal Presentations | Clarity, speed, tracking, flexibility, interaction, topic coverage, confidence |
| Written | Grammar, appearance, ease of reading, topic coverage |
| Emotional intelligence | Strength, timing, effectiveness |
| Technical communication | Accuracy, ease of reading, topic coverage |
| **Critical Thinking** | |
| Reasoning & Judgments | Logic, analysis, multiple viewpoints, make conclusions |
| Systems Thinking | Understanding how parts of a whole interact to produce an outcome |
| Solve Problems | Conventional and innovative solutions, ask questions that clarify issue |
| Research | Veracity, relevancy, citation, integration with project |
| **Creativity** | |
| Big Ideas | Innovative and inspiring concepts |
| Creative Process | Brainstorming, sketching, modeling, writing |
| Growth of Idea | Feedback, combine with other ideas, discard pieces, add pieces |
| Implementation | See idea put into reality, sustain idea over period of time, revise but keep core concept |
